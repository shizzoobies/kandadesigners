Heat, done well: local font package

body-regular.woff and body-bold.woff are copied from the existing nutrition
course in this repository. They are used under the local CSS alias Cedar
for body text and controls. The prior project font notes describe the
supplied web fonts as licensed; this upgrade adds no new font download
or license claim. Retain the project's original license records.

Headings use the installed Georgia system serif with a generic serif
fallback. No external font service or CDN is used.

The pre-existing display-regular.woff and display-medium.woff files are
retained for provenance but are not requested by the upgraded stylesheet.
