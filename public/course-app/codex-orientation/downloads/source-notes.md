# Codex desktop orientation source notes

Checked September 23, 2026 against current official OpenAI documentation.
This is independent K & A Performance training.

- Desktop quickstart: https://learn.chatgpt.com/docs/quickstart
  The current official guide calls the download the ChatGPT desktop app and
  offers Codex through the product selector. The narration covers this naming
  explicitly while allowing versions that already open directly in Codex.
- Local projects: https://learn.chatgpt.com/docs/projects
  A local project provides access to folders on the computer. A ChatGPT project
  with uploaded sources is not the same as selecting a local project folder.
- Permissions: https://learn.chatgpt.com/docs/permission-modes
  Approval prompts are not a guarantee that every file edit waits for a click.
  Existing workspace protections stay in place throughout the example.
- Review: https://learn.chatgpt.com/docs/code-review
  The review pane requires a Git repository. This lesson does not require Git
  setup and also teaches the direct browser check for the included starter.
- Windows: https://learn.chatgpt.com/docs/windows/windows-app
  Native Windows use is supported. No WSL or terminal setup is required by
  the illustrated reading-list exercise in this video.
- Prompting: https://learn.chatgpt.com/docs/prompting
  Examples state the requested outcome, preserved behavior, and verification.

All app screens are teaching illustrations, not actual recordings or exact
UI instructions. Labels can vary by app version. The reading-list examples
