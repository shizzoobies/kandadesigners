Connect a tool with MCP

MCP (Model Context Protocol) is a standard way to give Claude Code access to other tools and data, like Adobe Creative Cloud, your file storage, or a database. You add a connector once with claude mcp add, authorize it, and it is then available in your sessions. Add the Adobe Creative connector below and watch Claude use it.

Connectors are how Claude Code reaches your real tools. You added one, confirmed it, and watched Claude call it. Next, you build something for real.
