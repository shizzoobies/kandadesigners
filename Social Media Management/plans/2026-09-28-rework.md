## Working rules for parallel builds

- Reel work in D:\kap-reel goes in its own paths only: `src/social/<slot>/`
  (own entry file with registerRoot, so Root.tsx is never edited),
  `scripts/social/<slot>/`, `out/social/<slot>/`. Shared files (src/lib,
  src/components, config, scripts/*.ts) are imported read-only.
- Render: `node node_modules/@remotion/cli/remotion-cli.js render src/social/<slot>/index.ts <Comp> out/social/<slot>/<name>.mp4 --concurrency 3`.
  `npx` breaks on the ampersand path.
- No git commits by agents. No R2 uploads, no Metricool calls, no status changes
  to approved. Claude commits and releases after Alex reviews.
