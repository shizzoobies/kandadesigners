# Admin Backend, Phases 0 and 1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up an internal admin at `admin.ka-performancefl.com` that proves the Cloudflare Access → Worker → D1 chain end to end (Phase 0), then delivers the first useful screen: clients with their links and notes (Phase 1).

**Architecture:** A new `admin/` directory holds a standalone Astro SSR app deployed as its own Worker (`ka-admin`), bound to a dedicated D1 database (`ka-admin`). Cloudflare Access gates the hostname and passes a signed JWT; Astro middleware validates that JWT against the team's JWKS, resolves the email to a row in `users`, and puts the identity on `Astro.locals`. The app **denies by default**, so it is safe even on its `workers.dev` URL where Access does not apply. Pages are server-rendered with real `<form>` POSTs and redirect-after-write; there is essentially no client JS.

**Tech Stack:** Astro 5 (`output: 'server'`), `@astrojs/cloudflare` adapter, Cloudflare Workers, D1 (SQLite), Cloudflare Access (JWT via `Cf-Access-Jwt-Assertion`), vitest for unit tests, plain hand-written CSS.

## Global Constraints

- **Never run `npm install` in the repo root.** npm 11 strips the top-level `@emnapi/core` and `@emnapi/runtime` entries from the site's `package-lock.json` on Windows, which breaks the Cloudflare build. All installs happen inside `admin/`, which has its own lockfile. After any install, `git status --short package-lock.json` MUST be empty.
- **Do NOT add Tailwind to `admin/`.** Tailwind's platform-specific wasm optional dependencies are the origin of the emnapi problem. The admin uses plain CSS ported from the mockup.
- **`npm run <script>` is broken on this repo path** because of the `&` in `D:\K & A Performance Site`. Invoke tools through node directly, e.g. `node ./node_modules/astro/astro.js build`. Same reason `npx` does not work here.
- **Money is integer cents.** No floats. Column names end in `_cents`.
- **Dates are `TEXT` `YYYY-MM-DD`. Timestamps are ISO-8601 UTC `TEXT`.**
- **"Today" is computed in `America/New_York`, never UTC.**
- **No em dashes in any user-visible copy.** No pill or chip UI: status is a 2px left rule plus a mono caps label.
- **Amber (`#D97706`) is never text on a light background** (fails AA). Buttons and rules only, with espresso text on amber.
- Palette: canvas `#F8F5F2`, surface `#FFFDF9`, ink `#221C15`, muted `#6C635A`, accent rust `#9A3412`, accent-hot `#7C2D12`, amber `#D97706`, teal `#0B302D`/`#134E4A`, light teal `#5EEAD4`.
- **The app denies by default.** Any request without a valid Access identity gets 403, regardless of hostname.

```js
function b64url(bytes) {
  let bin = '';

async function makeKeypair() {
```

Create `admin/src/lib/access.js`:

```js
// Verifies Cloudflare Access JWTs. Pure crypto plus a JWKS fetch; knows nothing
// about D1, Astro, or this app's notion of a user.
//
// Docs: https://developers.cloudflare.com/cloudflare-one/identity/authorization-cookie/validating-json/

const JWKS_TTL_MS = 60 * 60 * 1000;

let jwksCache = { at: 0, domain: null, keys: null };

export class AccessError extends Error {}

export function __resetJwksCache() {
  jwksCache = { at: 0, domain: null, keys: null };
}

function b64urlToBytes(input) {
  const pad = input.length % 4 === 0 ? '' : '='.repeat(4 - (input.length % 4));
  const b64 = input.replace(/-/g, '+').replace(/_/g, '/') + pad;
  const bin = atob(b64);
  const out = new Uint8Array(bin.length);
  for (let i = 0; i < bin.length; i += 1) out[i] = bin.charCodeAt(i);
  return out;
}

function b64urlToJson(input) {
  try {
    return JSON.parse(new TextDecoder().decode(b64urlToBytes(input)));
  } catch {
    throw new AccessError('malformed_token');
  }
}

async function getJwks(teamDomain, fetchImpl, now) {
  const fresh = jwksCache.keys
    && jwksCache.domain === teamDomain
    && now - jwksCache.at < JWKS_TTL_MS;
  if (fresh) return jwksCache.keys;

  const res = await fetchImpl(`https://${teamDomain}/cdn-cgi/access/certs`);
  if (!res.ok) throw new AccessError(`jwks_fetch_failed_${res.status}`);
  const body = await res.json();
  if (!Array.isArray(body?.keys) || body.keys.length === 0) {
    throw new AccessError('jwks_empty');
  }
  jwksCache = { at: now, domain: teamDomain, keys: body.keys };
  return body.keys;
}

export async function verifyAccessJwt(token, opts) {
  const { teamDomain, aud, fetchImpl = fetch, now = Date.now() } = opts;
  if (!token) throw new AccessError('missing_token');

  const parts = token.split('.');
  if (parts.length !== 3) throw new AccessError('malformed_token');
  const [headerPart, payloadPart, signaturePart] = parts;

  const header = b64urlToJson(headerPart);
  if (header.alg !== 'RS256') throw new AccessError('unexpected_alg');
  if (!header.kid) throw new AccessError('missing_kid');

  const keys = await getJwks(teamDomain, fetchImpl, now);
  const jwk = keys.find((k) => k.kid === header.kid);
  if (!jwk) throw new AccessError('unknown_kid');

  const key = await crypto.subtle.importKey(
    'jwk',
    { kty: jwk.kty, n: jwk.n, e: jwk.e, alg: 'RS256', ext: true },
    { name: 'RSASSA-PKCS1-v1_5', hash: 'SHA-256' },
    false,
    ['verify']
  );

  const valid = await crypto.subtle.verify(
    'RSASSA-PKCS1-v1_5',
    key,
    b64urlToBytes(signaturePart),
    new TextEncoder().encode(`${headerPart}.${payloadPart}`)
  );
  if (!valid) throw new AccessError('bad_signature');

  const payload = b64urlToJson(payloadPart);
  const audList = Array.isArray(payload.aud) ? payload.aud : [payload.aud];
  if (!audList.includes(aud)) throw new AccessError('aud_mismatch');
  if (typeof payload.exp !== 'number' || payload.exp * 1000 <= now) {
    throw new AccessError('expired');
  }
  if (payload.iss !== `https://${teamDomain}`) throw new AccessError('iss_mismatch');
  if (!payload.email) throw new AccessError('missing_email');

  return { email: String(payload.email).toLowerCase(), payload };
}
```

```js
// Decides where an identity may come from. Deliberately the only file that
// knows about the dev bypass, so that policy has exactly one home and one
// set of tests.

import { verifyAccessJwt } from './access.js';

function readToken(request) {
  const header = request.headers.get('Cf-Access-Jwt-Assertion');
  if (header) return header;

  const cookie = request.headers.get('cookie');
  if (!cookie) return null;
  for (const part of cookie.split(';')) {
    const idx = part.indexOf('=');
    if (idx === -1) continue;
    if (part.slice(0, idx).trim() === 'CF_Authorization') {
      return decodeURIComponent(part.slice(idx + 1).trim());
    }
  }
  return null;
}

export async function resolveEmail({ request, env, verify = verifyAccessJwt }) {
  const token = readToken(request);

  if (token) {
    try {
      const { email } = await verify(token, {
        teamDomain: env.ACCESS_TEAM_DOMAIN,
        aud: env.ACCESS_AUD,
      });
      return { email, source: 'access' };
    } catch {
      // A present-but-invalid token is never allowed to fall through to the
      // dev bypass. Failing closed here is the point of this whole module.
      return null;
    }
  }

  // Exact string match, and DEV_EMAIL must also be set. Anything else is prod.
  if (env.ENVIRONMENT === 'development' && env.DEV_EMAIL) {
    return { email: String(env.DEV_EMAIL).toLowerCase(), source: 'dev' };
  }

  return null;
}
```

```js
// Money is always integer cents in the database. Dates are stored as
// YYYY-MM-DD text. "Today" is an Eastern-time concept here, never UTC,
// because otherwise anything due today reads as overdue after 8pm local.

const EASTERN = 'America/New_York';

const moneyFmt = new Intl.NumberFormat('en-US', {
  style: 'currency', currency: 'USD', minimumFractionDigits: 2,
});

export function money(cents) {
  return moneyFmt.format((Number(cents) || 0) / 100);
}

export function todayInEastern(nowMs = Date.now()) {
  // en-CA gives YYYY-MM-DD directly.
  return new Intl.DateTimeFormat('en-CA', {
    timeZone: EASTERN, year: 'numeric', month: '2-digit', day: '2-digit',
  }).format(new Date(nowMs));
}

export function nowIso(nowMs = Date.now()) {
  return new Date(nowMs).toISOString();
}

export function humanDate(ymd) {
  if (!ymd) return '';
  const [y, m, d] = String(ymd).split('-').map(Number);
  if (!y || !m || !d) return '';
  return new Intl.DateTimeFormat('en-GB', {
    day: 'numeric', month: 'short', year: 'numeric', timeZone: 'UTC',
  }).format(new Date(Date.UTC(y, m - 1, d)));
}
```

```js
import { resolveEmail } from './lib/identity.js';
import { getUserByEmail, touchUser } from './lib/db.js';
import { nowIso } from './lib/format.js';

const DENY = 'Not authorised. This application is restricted to K & A Performance staff.';

export const onRequest = defineMiddleware(async (context, next) => {
  const env = context.locals.runtime?.env;
  if (!env?.DB) {
    return new Response('Server misconfigured: no database binding.', { status: 500 });
  }

  const identity = await resolveEmail({ request: context.request, env });
  if (!identity) return new Response(DENY, { status: 403 });

  const user = await getUserByEmail(env.DB, identity.email);
  if (!user) return new Response(DENY, { status: 403 });

  context.locals.user = {
    id: user.id,
    email: user.email,
    name: user.name,
    role: user.role,
    clientId: user.client_id,
    source: identity.source,
  };

  // Fire-and-forget so the write never delays the response.
  context.locals.runtime.ctx?.waitUntil(touchUser(env.DB, user.id, nowIso()));

  return next();
});
```

```js
import { createClient, updateClient, archiveClient } from '../../lib/db.js';
import { nowIso } from '../../lib/format.js';

const seeOther = (location) => new Response(null, { status: 303, headers: { Location: location } });

export async function POST({ request, locals }) {
  const db = locals.runtime.env.DB;
  const form = await request.formData();
  const intent = form.get('intent');
  const iso = nowIso();

  const fields = {
    name: String(form.get('name') ?? '').trim(),
    company: String(form.get('company') ?? '').trim(),
    email: String(form.get('email') ?? '').trim(),
    phone: String(form.get('phone') ?? '').trim(),
    status: String(form.get('status') ?? 'active'),
    source: String(form.get('source') ?? '').trim(),
  };

  if (intent === 'create') {
    if (!fields.name) return seeOther('/clients?error=name');
    const id = await createClient(db, { ...fields, createdAt: iso });
    return seeOther(`/clients/${id}`);
  }

  const id = Number(form.get('id'));
  if (!Number.isInteger(id) || id <= 0) return seeOther('/clients?error=id');

  if (intent === 'update') {
    if (!fields.name) return seeOther(`/clients/${id}?error=name`);
    await updateClient(db, id, { ...fields, updatedAt: iso });
    return seeOther(`/clients/${id}?saved=1`);
  }

  if (intent === 'archive') {
    await archiveClient(db, id, iso);
    return seeOther('/clients?archived=1');
  }

  return seeOther('/clients?error=intent');
}
```

```js
const seeOther = (location) => new Response(null, { status: 303, headers: { Location: location } });

// Only ever redirect to a same-origin path, never to a caller-supplied URL.
function safeReturn(raw, fallback) {
  const value = String(raw ?? '');
  return value.startsWith('/') && !value.startsWith('//') ? value : fallback;
}

export async function POST({ request, locals }) {
  const db = locals.runtime.env.DB;
  const form = await request.formData();
  const intent = form.get('intent');
  const back = safeReturn(form.get('returnTo'), '/clients');

  if (intent === 'create') {
    const body = String(form.get('body') ?? '').trim();
    if (!body) return seeOther(`${back}?error=note`);
    await createNote(db, {
      entityType: String(form.get('entityType') ?? 'client'),
      entityId: Number(form.get('entityId')),
      body,
      authorEmail: locals.user.email,
      pinned: form.get('pinned') === '1',
      createdAt: nowIso(),
    });
    return seeOther(back);
  }

  if (intent === 'delete') {
    const id = Number(form.get('id'));
    if (Number.isInteger(id) && id > 0) await deleteNote(db, id);
    return seeOther(back);
  }

  return seeOther(`${back}?error=intent`);
```

```js
import { createLink, deleteLink } from '../../lib/db.js';

const seeOther = (location) => new Response(null, { status: 303, headers: { Location: location } });

function safeReturn(raw, fallback) {
  const value = String(raw ?? '');
  return value.startsWith('/') && !value.startsWith('//') ? value : fallback;
}

// Only http and https. Blocks javascript: and data: URLs, which would
// otherwise become a stored-XSS vector the moment the link is rendered.
function safeUrl(raw) {
  try {
    const parsed = new URL(String(raw));
    return ['http:', 'https:'].includes(parsed.protocol) ? parsed.toString() : null;
  } catch {
    return null;
  }
}

const KINDS = ['live', 'staging', 'repo', 'drive', 'gbp', 'social', 'dashboard', 'other'];

export async function POST({ request, locals }) {
  const db = locals.runtime.env.DB;
  const form = await request.formData();
  const intent = form.get('intent');
  const back = safeReturn(form.get('returnTo'), '/clients');

  if (intent === 'create') {
    const clientId = Number(form.get('clientId'));
    const label = String(form.get('label') ?? '').trim();
    const url = safeUrl(form.get('url'));
    const rawKind = String(form.get('kind') ?? 'other');
    const kind = KINDS.includes(rawKind) ? rawKind : 'other';

    if (!Number.isInteger(clientId) || clientId <= 0) return seeOther('/clients?error=id');
    if (!label) return seeOther(`${back}?error=label`);
    if (!url) return seeOther(`${back}?error=url`);

    await createLink(db, { clientId, label, url, kind, sortOrder: 0 });
    return seeOther(back);
  }

  if (intent === 'delete') {
    const id = Number(form.get('id'));
    if (Number.isInteger(id) && id > 0) await deleteLink(db, id);
    return seeOther(back);
  }

  return seeOther(`${back}?error=intent`);
}
```

**Spec coverage.** Architecture: Tasks 1 and 5. Auth including the dev-bypass negative test: Tasks 2, 3, 5. Data model, all nine tables and the three conventions: Task 4. Clients, links, contacts, notes: Tasks 6, 7, 8. Phase 0's CPU measurement: Task 5 step 10.4, recorded in Task 9. Deny-by-default: Task 5 steps 6 and 9. Confirming the Access hostname: Task 5 step 10.1.

**Deliberately out of this plan**, and therefore still open: projects, invoices, retainers, follow-ups, the dashboard's six rules, the digest Worker, and the Firebase tracker retirement. Those are Phases 2 through 5 and get their own plan once the CPU number is known, per the spec.

**Naming consistency.** `resolveEmail` returns `{ email, source }` in Task 3 and is consumed with exactly those names in Task 5. `db.js` functions all take the D1 binding first. `safeReturn` is defined identically in both `notes.js` and `links.js`; that duplication is deliberate rather than a shared import, since each endpoint file stays self-contained and the function is four lines. `KIND_LABEL` keys in `clients/[id].astro` match the `KINDS` array in `links.js` and the CHECK constraint in the migration.

**One gap accepted knowingly:** `clients/[id].astro` renders note bodies and link labels as text through Astro's escaping, so stored markup is inert, and `links.js` rejects non-http schemes. There is no CSRF token. The app is single-user behind Access with `SameSite` cookies set by Cloudflare, so the realistic attack requires an authenticated session plus a hostile page; worth adding when the app gains more users, and noted here so it is a decision rather than an oversight.
