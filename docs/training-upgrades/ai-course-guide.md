# Illustrated guide for AI training

The existing fictional safety instructor was adapted into a charcoal-and-rust
studio outfit for the AI lessons. Her transparent portrait accompanies
Victoria's prerecorded ElevenLabs narration in both the orientation and main
course. Audio states update from the actual media element. A warm highlight
indicates playback, with reduced-motion support and no lip synchronization.

Both video guides include her in the opening scene of each chapter. The
demonstrations retain their original area, timing, narration, and captions.
The asset is `assets/ai-training-guide-v1.webp` in each course-app directory.
UI behavior and styling are isolated in guide-ui.js and guide-ui.css.
Both course pages continue using the shared ampersand favicon and signup gate.

Authoring source, original transparent PNG, exact built-in image-generation
prompt, and verification notes are in Explainer Videos/illustrated-guide.
Previous video editions and ZIPs were retained separately. Updated media and
posters use the 20260923-guide cache version.

Verified at 360, 768, and 1280 pixels, including actual playback state changes,
keyboard seeking, captions, video playback, and console checks. Full media
decode passed for both exports; stationary holds passed for all 46 scenes.
The Astro build and SEO check passed for all 43 routes.
