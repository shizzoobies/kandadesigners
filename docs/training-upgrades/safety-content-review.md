# Safety module content review

September 22, 2026. Focused corrections made during the visual upgrade. This is not a certification or a substitute for qualified review of the final course.

| Topic | Correction | Primary reference |
| --- | --- | --- |
| Ladder access | Use side rails at least 3 feet above the landing, with the permitted secured alternative; remove the implication that every repaired ladder is prohibited. | [OSHA 1926.1053](https://www.osha.gov/laws-regs/regulations/standardnumber/1926/1926.1053) |
| Open edges | Require protection while exposure exists, rather than allowing guardrail restoration by the end of a shift. | [OSHA 1926.502](https://www.osha.gov/laws-regs/regulations/standardnumber/1926/1926.502) |

## Audio production

Ten short, optional screen introductions were generated using ElevenLabs Bella (`hpp4J3VqNfWAUOO0d1Us`), `eleven_multilingual_v2`, with MP3 44.1 kHz/128 kbps output. The scripts are the public `narration.js` file, which also supplies the on-screen transcripts. The user explicitly authorized use of their account credits.

These are introductions, not full-course narration. The interface labels them accordingly. Audio only starts after Listen is selected and pauses when its dialog closes. MP3s are generated during production, so opening a course never calls ElevenLabs or uses credits. The API credential is read only by the local generation script from the git-ignored `.dev.vars` file.

[ElevenLabs speech generation reference](https://elevenlabs.io/docs/api-reference/text-to-speech/convert).
