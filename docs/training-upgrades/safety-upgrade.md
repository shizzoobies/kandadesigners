# Hazard recognition upgrade

Status: approved for production on 2026-09-22. Release the safety course onto the latest production branch through the existing Git-triggered Cloudflare Pages build.

## What changed

- Readable Parson typography, restrained charcoal and warm safety-yellow palette, and a cover that gives the new image its own space.
- A generated fictional construction scene shared by the cover and hazard hunt. Six HTML hotspots align with the scene's 3:2 coordinates.
- Optional location guides, an enlarged inspection view, equivalent labeled list controls, and corrective actions in hazard feedback.
- Assistance available immediately, with course progression, checklist and completion preserved. Multiple-choice checks are replaced by the control workbench and the inspection board described in [visual-activities.md](visual-activities.md).
- Ten optional audio introductions with matching text transcripts. The gold "Play introduction" control sits between Back and Next. It opens an inline bottom tray that reserves space beneath the lesson instead of covering it. Closing the tray pauses playback. Screen navigation keeps the tray open, updates the transcript and source, and waits for explicit playback. Audio assets are local and do not call an API during playback.
- A first illustrated hardhat guide appears beside the player, using the current K & A Performance wordmark on the helmet badge. Ready, Speaking, Paused and Complete states follow playback. This is a static character concept, with no lip synchronization or chatbot interaction. See [course-guide-concept.md](course-guide-concept.md) for the source, optimized asset and exact generation prompt.
- Nine landscape SVG inspection details replace the static side photos on screens 4 through 6. Each illustration and takeaway belongs to its tab panel, so pointer and keyboard selection change the text and artwork together. Illustrations stack beneath the text on narrow screens.
- Focusable mobile reading regions and responsive illustration height.
- Decorative screen stamps and illustration codes removed. Functional course progress remains. Audio now uses a custom charcoal-and-gold player with labeled play/pause/replay, elapsed time, keyboard seeking and mute controls. Dismissals use "Hide audio", "Back to lesson" and "Return to course" instead of X icons or generic Close labels.
- Focused safety-content corrections, recorded separately with references.
